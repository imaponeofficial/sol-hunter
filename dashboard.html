Backend — Estrutura de Arquivos
O backend Node.js deve rodar em paralelo com este dashboard. Estrutura:
sol-hunter/
├── dashboard.html          ← Este arquivo
├── backend/
│   ├── index.js            ← Servidor principal (Express)
│   ├── monitor.js          ← Ciclo de monitoramento (Jupiter API)
│   ├── buyer.js            ← Lógica de compra (Jupiter Swap)
│   ├── seller.js           ← Lógica de venda automática
│   ├── wallet.js           ← Gerenciamento de carteira
│   ├── db.js               ← Supabase client
│   └── config.js           ← Configurações
└── package.json
